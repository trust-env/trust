# Trust runtime crates

Every project generated by `trust` depends on these small crates. They live
in this repository so a generated project only needs public access to
`https://github.com/trust-env/trust.git` — no private repository, no SSH key.

| Crate    | Pulled in when                                   | Provides |
|----------|--------------------------------------------------|----------|
| `common` | always (use cases, storages, `main.rs`)          | `EntityId`, `UseCase`, `Storage`, `StorageListQuery`, `StoragePredicate`, `StoragePredicateOperator`, `SQLConnector`, `HttpPresenter`, `HttpError`, `HttpResult`, `start_http_server` |
| `auth`   | an HTTP route uses `auth {}` / `auth: required`  | `UserContext` / `OptionalUserContext` (HS256 JWT read from `Authorization: Bearer`, secret from `JWT_SECRET`), `JwtClaims` |

They are standalone packages (not members of the compiler's own crate), so
`cargo build` at the repository root is unaffected.

To build a generated project fully offline, pass `--vendor=<trust repo>/runtime`
to the CLI: it copies these crates into `out/vendor/` and rewrites the git
dependencies to path dependencies.
